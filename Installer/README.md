# Windows installer

`setup.iss` is compiled by the GitHub Actions release workflow with these preprocessor values:

- `AppVersion`: numeric version derived from the GitHub Release tag.
- `PublishDir`: directory generated by `dotnet publish`.

The installer copies only the publish output. It does not create or copy the SQLite database. The application remains responsible for creating the database and applying migrations under `%LOCALAPPDATA%\CalculadoraFilamentoPro`.

The project already defines a MAUI app icon. Therefore, `icon.ico` is optional: shortcuts and the uninstaller use the icon embedded in `CalculadoraFilamentoPro.View.exe`. `wizard.bmp` and `wizard-small.bmp` are also optional and are not needed with Inno Setup's default wizard artwork. Add them later only when custom branding is required, then reference them from `[Setup]` with `SetupIconFile`, `WizardImageFile`, or `WizardSmallImageFile`.
